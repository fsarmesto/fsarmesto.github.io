# fsarmesto.github.io

- `.well-known/assetlinks.json`: verificación de la app Android de [Liquidación arbitral FCVB](https://github.com/fsarmesto/liquidacion-arbitral-fcvb) (Trusted Web Activity). Sin este fichero la app se abre con la barra del navegador. La huella es la de la clave de firma de la app; si se cambia la clave, hay que cambiarla aquí.
- `index.html`: redirige a la app.
